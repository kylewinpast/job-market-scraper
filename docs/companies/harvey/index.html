How the ghost score works

Every day we snapshot Harvey’s job board and record which postings are still listed. A posting earns ghost points for staying up 30/60/90+ days (+20/+35/+50) and for being reposted under a new listing ID (+25 for 2×, +40 for 3×+), capped at 100. Read the full methodology.
