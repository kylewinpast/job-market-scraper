How it works

Every day we snapshot the job boards of 46 US tech companies and record which postings are still listed. A posting earns ghost points when it stays up for a long time or keeps getting reposted under a new listing ID:

SignalPoints
Listed 30+ days+20
Listed 60+ days+35
Listed 90+ days+50
Reposted 2× (same role, new listing)+25
Reposted 3× or more+40
Maximum score100

These are heuristics based on public posting data, not an accusation against any employer — some roles are simply evergreen or hard to fill.
