Methodology

How we score ghost jobs

Every day we snapshot the job boards and record which postings are still listed.

SignalPoints
Listed 30+ days+20
Listed 60+ days+35
Listed 90+ days+50
Reposted 2× (same role, new listing)+25
Reposted 3× or more+40
Maximum score100

Heuristics based on public posting data, not an accusation against any employer — some roles are simply evergreen or hard to fill.
